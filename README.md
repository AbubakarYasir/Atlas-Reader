# Atlas Reader

Atlas Reader is an offline-first Flutter bookmark manager for PDFs. It mirrors
PDF outline bookmarks into a local SQLite database so users can browse, search,
edit, and organize their reading structure without locking that work into one
reader application.

The full product and accessibility roadmap is in [PLAN.md](PLAN.md).

## Current status

The project is a Windows-focused proof of concept moving into hardening. PDF
outline reading and writing use `syncfusion_flutter_pdf`; local storage and
search use Drift with SQLite FTS5.

Implemented today:

- Recursive PDF outline extraction and nested bookmark display.
- Hierarchical database storage using `parent_id` and cascading deletion.
- Path-based PDF/database reconciliation, which distinguishes duplicate titles
  under different parents.
- Search, grouping by book or tag, edit/delete, and remove-all-bookmarks for a
  selected book.
- Versioned snapshots containing complete outline path keys.
- Safe PDF replacement: validate output, write `filename.pdf.tmp`, validate it
  again, then use a recovery-file swap to preserve the original on failure.
- Material-safe outline rows that avoid the nested `ListTile` ink warning.

Not implemented yet: a PDF reader view, EPUB support, UUID-based conflict
resolution, library scanning, Android SAF support, and rich descriptions in
PDF metadata.

## Data-safety behaviour

Atlas never writes PDF output directly over the source file. A write follows
this sequence:

1. Validate generated bytes and expected page count.
2. Write and flush `<document>.pdf.tmp`.
3. Re-open and validate that temporary PDF.
4. Move the original to `<document>.pdf.atlas-backup`.
5. Promote the temporary file, then remove the recovery file.

If promotion fails, Atlas restores the original. If a recovery file already
exists, Atlas stops and explains the recovery action instead of overwriting it.

## Architecture

| Area | Main files |
| --- | --- |
| UI and bookmark tree | `lib/main.dart`, `lib/widgets/accessible_bookmark_tile.dart` |
| Persistence and FTS | `lib/database.dart`, `lib/file_snapshot_state.dart` |
| PDF outline read/write | `lib/pdf_engine.dart`, `lib/pdf_safe_file_writer.dart` |
| Reconciliation | `lib/sync_engine.dart`, `lib/sync_diff.dart` |
| Hierarchy helpers | `lib/bookmark_tree.dart` |

Snapshots use an internal separator rather than a visible `>` character. For
example, the visible path `Volume 1 > Chapter 2 > Section A` becomes an
unambiguous key; two sibling branches may therefore both contain `Index`
without colliding.

## Development

Prerequisites: Flutter SDK compatible with Dart `^3.12.1`.

```powershell
cd atlas_poc
flutter pub get
flutter test
flutter analyze
flutter run -d windows
```

The unit suite covers tree generation, full path-key construction, legacy
snapshot compatibility, and PDF/database diff calculations. The widget suite
starts the app with an in-memory database.
