## Recommended one-command qualification

From the repository root:

```powershell
.\tools\bench\run-n1-qualification.ps1
```

If Qt is installed elsewhere:

```powershell
.\tools\bench\run-n1-qualification.ps1 `
  -QtRoot D:\Qt\6.10.3\msvc2022_64
```

The qualification runner:

1. configures the canonical Visual Studio 2022 x64 preset;
2. builds Release;
3. runs Release CTest;
4. collects a six-run English/LTR system-theme baseline;
5. collects a three-run Arabic/RTL dark-theme baseline;
6. prints the remaining manual visual/DPI checklist.

It writes raw machine-specific reports under ignored `artifacts/bench/`.

## Manual build path

```powershell
$env:CMAKE_PREFIX_PATH = 'C:\Qt\6.10.3\msvc2022_64'
cmake --preset windows-msvc2022
cmake --build --preset windows-release
ctest --preset windows-release
```

If the executable cannot locate Qt DLLs when launched directly, prepend the kit's `bin` directory or pass it to the harness with `-QtBin`.

## Direct measurement commands

English/system theme:

```powershell
.\tools\bench\measure-windows-shell.ps1 `
  -Iterations 6 `
  -Language en `
  -Theme system `
  -QtBin C:\Qt\6.10.3\msvc2022_64\bin
```

Arabic/dark smoke measurement:

```powershell
.\tools\bench\measure-windows-shell.ps1 `
  -Iterations 3 `
  -Language ar `
  -Theme dark `
  -QtBin C:\Qt\6.10.3\msvc2022_64\bin
```

The harness records:

- process launch → input-idle candidate;
- QML loaded time;
- first swapped frame time;
- working set/private memory after settling;
- one-second normalized CPU sample;
- deterministic window-resize frame interval p50/p95/p99;
- clean shutdown timestamp.

The first process launch is labeled a **cold candidate**, not a guaranteed laboratory cold-cache run. Do not compare numbers gathered under different cache, power, refresh, VM, or build conditions as if they were identical.

## N1 interpretation

N1 establishes a **zero-feature cost floor**, not a marketing performance claim. Future checkpoints compare against this baseline so we can identify whether PDF rendering, indexing, bookmarks, or annotations introduce regressions.

A regression discovered later must be attributed to a named subsystem rather than dismissed as “Qt overhead.”
