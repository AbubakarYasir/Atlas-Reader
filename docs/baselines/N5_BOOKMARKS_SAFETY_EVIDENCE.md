## N5.1 Capability check — 2026-11-02

- `src/core/document/CapabilityPolicy` (pure C++): `assessCapabilities(FileFacts, PdfFacts, RevisionFacts)` → `DocumentCapabilities` + ordered reasons. Blocking order: external change, not inspected, malformed, certified/signed, read-only file, read-only folder, sharing lock; PDF permissions may allow outline (modify or assemble) and annotations separately; the owner password lifts permission flags; extraction-restricted PDFs are not text-searched. Tests: `atlas_capability_policy` (every row of the table, partial permissions, multiple reasons).
- `src/app/document/DocumentCapabilityCheck`: `QpdfInspector` runs `qpdf --json=2` (encrypt, acroform; trailer → catalog for `/Perms /DocMDP`), 20 s timeout, password via `--password-file=-` (never on the command line or disk); `FileFactsProbe` uses file attributes, a deny-write share probe (`CreateFileW`, read access only) and the folder ACL (no temporary files); `RevisionStamp` (size + UTC modification time). Tests: `atlas_qpdf_inspector` (parsing of recorded JSON; with qpdf: A001, A009 wrong/user/owner, A010, Unicode-named copy, external change, read-only copy where the account honours it, SHA-256 of sources unchanged). Local run with qpdf 11.9 passes; Windows CI uses the pinned 12.4.1 package.
- `ReaderController`: `capability` role, background check when a tab becomes ready, `recheckCapabilities(index)`; the first stamp is the baseline, a reopen accepts the file as it is.
- UI: status-bar chip and explanation popup (EN/AR/UR, 26 new strings, `check-strings` PASS 298 keys). Rendered: A010 shows *Signed* with "certified by its author".
- Packaging: CI downloads the SHA-256-pinned official qpdf 12.4.1 MSVC64 package, sets `ATLAS_QPDF` for tests and copies the same minimal runtime as the N2 selected route into `qpdf/` with its licence and notice.
- CI repair: the N2 content-fidelity workflow pins Python 3.12 (Pillow 11.3.0 had no wheel for the runner's newer Python).

## N5.2 Local overlay — 2026-11-03

Status: **Implemented** (automated checks on Linux; Windows CI evidence is recorded when the branch runs). Decision: [ADR-0008](../decisions/ADR-0008-bookmark-overlay-and-location-envelope.md) (Proposed until `N5 PASS`).

- `src/core/bookmarks/LocationEnvelope` (pure C++): `atlas-location/1;scheme=pdf;page=…;label=…;kind=…;left/top/right/bottom/zoom`. Kinds XYZ, Fit, FitH, FitV, FitR, FitB, FitBH, FitBV with per-kind coordinate rules; coordinates are fractions 0–1 of the displayed page (origin top-left); zoom 0–64; numbers written with `std::to_chars` (exact, locale-free); labels and extension values percent-encoded UTF-8; unknown keys kept in order; newer major version → `unsupportedVersion`, unknown scheme → `unsupportedScheme`, both kept as raw text by callers; 8 KiB limit.
- `src/core/bookmarks/BookmarkOverlay` (pure C++): `BookmarkNode`, `BaseSnapshot`, `StorageState`, `StorageEvent`; one 22-row transition table; `EmbedProof` (written, validated, reopened, re-indexed, new revision) required for `embedVerified`; `validateNode`, `validateTree` (unique IDs, one document, parents present, no cycles, depth ≤ 256, contiguous sibling positions), `validateAgainstBase` ("no false Embedded"), `embeddedNodesFromBase`, strict UTF-8 check, random 128-bit IDs.
- Schema 5 (`SqliteLibraryIndex` migration 5): `bookmark_overlays`, `bookmark_base_snapshots`, `bookmark_base_nodes`, `bookmark_nodes` (with `CHECK`s for state, base key and conflict fields, tombstone column), `bookmark_node_tags`. Adds tables only.
- `src/app/bookmarks/SqliteBookmarkOverlay`: opens an existing profile only (schema ≥ 5, Atlas application ID); `load` in one read transaction; `adoptBase` stores the first outline and creates Embedded nodes (earlier local nodes move after them), and reports `unchanged` or `needsReconcile` without writing for any later outline; `apply` checks the revision, transitions, base-key rules, "hidden and conflict nodes can't be edited", "source nodes are hidden, not removed", tree and base rules, then writes in one `BEGIN IMMEDIATE` transaction (WAL, `synchronous = FULL`); removals become tombstones and their IDs are retired; `documentsWithLocalWork` lists documents to offer after a restart.
- Tests: `atlas_bookmark_overlay` (UTF-8 edge cases; envelope round trips for every kind, Arabic labels, exact doubles, extensions; 17 malformed and 2 unsupported inputs; all 66 state × event pairs against an independently written table; every missing proof step; tree, depth, cycle, position and base rules). `atlas_bookmark_store` (no profile created on its own; non-Atlas database refused; schema-4 profile upgraded with library data intact; base adoption, unchanged and needs-reconcile; every state persisted across reopen; exact bytes for Arabic with spaces, Urdu with harakat and ZWJ, emoji, U+0000; tags in order with duplicates; a newer envelope kept; false Embedded, illegal transitions, editing hidden nodes, removing source nodes, orphaning children, stale revisions and reused IDs refused; tombstone row present; 10,000 nodes with 197-sibling move; crash recovery: a child process ends with `std::_Exit` before `COMMIT` in `apply` and in `adoptBase`, and right after a commit without closing; afterwards `integrity_check` is `ok` and no foreign key dangles). Existing `atlas_library_index` updated for schema 5.
- Local run (Linux container, g++ 13.3 with AddressSanitizer and UBSan, SQLite 3.45.1): all three test programs pass; also compiled warning-free with `-Wall -Wextra -Wpedantic -Wshadow -Wconversion` and Clang 18. Indicative timings with `-O2`, 3 runs: 10,000-node write 124–137 ms, load 11–12 ms, move with 197 shifts 30–37 ms. Not a Windows measurement; N5.3 records Windows Release numbers for the panel.
- Not in N5.2 (owned by later sub-stages, each with its test): reading the PDF outline into the overlay when a book opens and the Bookmarks panel → N5.3; reconciling a changed outline and the verified save that produces `EmbedProof` → N5.4; JSON/Markdown/CSV → N5.5.
