# Atlas Reader 0.8.0-beta.1 — Focused Reader Baseline

This is the first consolidated Windows beta checkpoint for Atlas Reader's
three core workflows: discovering books, navigating deep bookmarks, and reading
or writing standard ink annotations into PDFs. It is the owner-accepted C0
baseline for the checkpoint roadmap to 1.0.

## Highlights

- Scan multiple explicit folders for PDF and EPUB books without a cloud account.
- Open a PDF from anywhere without silently registering its parent folder.
- Search books and nested bookmarks globally with `Ctrl+K`, then jump to the
  exact saved page.
- Read PDFs continuously with zoom, page navigation, crop, brightness, and
  display themes.
- Draw pressure-aware pen strokes and translucent highlights, erase, undo,
  redo, and save standard page-isolated PDF `/Ink` annotations.
- Preserve PDF outlines, page count, document information, and XMP presence
  through validated temporary-file replacement with a recovery backup.
- Use the focused Windows shell in English or Arabic with keyboard and basic
  screen-reader semantics.

## Verification

The native suite covers direct external-PDF launch and Recents, mouse ink save
and reopen with page/outline/metadata preservation, and two-folder
Arabic/English library scanning plus bookmark search.

## Install and run

Download `atlas-reader-windows-v0.8.0-beta.1.zip`, verify it against the
included `.sha256` file, extract the complete archive, and run `atlas_poc.exe`.
Keep the executable, DLLs, and `data` directory together.

This beta is unsigned, so Windows SmartScreen may display a warning. Atlas does
not change system PDF associations automatically.

## Important limitations

- This beta modifies local PDFs. Test with copies and maintain independent
  backups of irreplaceable documents.
- PDF is the only full reading/writing format; EPUB is discovery-only.
- Descriptions and tags are still local SQLite data rather than portable PDF
  metadata.
- PDF cover fallback, complete bookmark editing, advanced annotations, native
  printing, full Arabic/RTL acceptance, and the installer are later checkpoints.
- The two skipped audits require user-supplied copied Arabic and English PDFs.

See `CHECKPOINTS.md` for the owner-test gates and the roadmap to stable 1.0.
