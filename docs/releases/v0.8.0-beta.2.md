# Atlas Reader 0.8.0-beta.2 — Reader Workspace

This corrected C1 build 4 is the owner-test candidate for the Windows reader
workspace. The final `v0.8.0-beta.2` tag remains held until explicit PASS.

## Highlights

- Use one shared PDF session per loaded tab, with lazy loading and a three-tab
  recent-session cache to reduce opening and switching stalls.
- Optionally restore tabs after restart using a Settings switch that is off by
  default.
- Browse Outline first, then lazy real Pages previews, Bookmarks, and
  Annotations from one collapsible, searchable panel.
- Jump to exact pages from every panel, the existing page field, or scrub bar.
- Choose Fit Page, Fit Width, or any entered zoom from 10% to 6400%, including
  values smaller than Fit, in both Read and Write modes.
- Generate first-page PDF covers in a background queue and keep every library
  card the same size across short, long, Arabic, and English metadata.
- Use localized right-click and keyboard context menus on books and tabs.
- Use a persistent sidebar on wide windows and a full-width modal navigation
  sheet on compact windows.
- Use localized English and Arabic controls with RTL layout, semantics, compact
  actions, and verified 200% text scaling.

Run the ten-step corrective C1 checklist in `CHECKPOINTS.md`, covering the
previously lagging PDF, tab switching, Outline-first navigation, real previews,
10% zoom, context menus, dirty-tab protection, covers/card geometry, Arabic,
keyboard access, and the opt-in restart setting.

Reply with an explicit PASS to authorize the `v0.8.0-beta.2` tag and GitHub
prerelease. A failure keeps C1 in progress until the defect and affected gates
are rerun.

## Important limitations

- This beta modifies local PDFs. Use copies for writing tests and keep an
  independent backup of irreplaceable documents.
- EPUB remains discovery-only.
- The two personal-file audits require owner-supplied copied Arabic and English
  PDF fixtures and are not counted as passing evidence.
- Pen, touch, HDD, and physical-printer qualification remain required at C9.
- The beta bundle is unsigned, so Windows SmartScreen may show a warning.
